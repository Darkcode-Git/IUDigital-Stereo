# IUDigital-Stereo
Jetpack Compose

Esta estructura del proyecto proporciona una implementación completa de la aplicación IU Digital Radio con:

Arquitectura limpia siguiendo el patrón MVVM
Interfaz de Composición Jetpack con diseño de Material 3
Integración de cámara y galería con el manejo adecuado de permisos
Retroalimentación háptica para interacciones del usuario
Simulación de reproducción de audio (se integraría con Media3 ExoPlayer en una app real)
Componente del visualizador de espectro
Pruebas unitarias para el ViewModel
Navegación entre pantallas
Componentes de interfaz adaptados
La aplicación está diseñada para Android SDK 34 (Android 14) con compatibilidad hacia atrás con Android 5.0 (nivel de API 21).
